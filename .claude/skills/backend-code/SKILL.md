# 手写后端代码

> **约定与为什么**在 `docs/基建/框架分层与权限约定.md` —— **动手前先读它**。
> 这个 skill 只讲**流程**：什么时候该手写、一条链要改哪几个文件、怎么验。

## 〇、先问一句：生成器做得了吗？

**能做的别手写。** 生成器产出的 CRUD 带菜单权限、字典、分页这些配套设施，
手写必漏其中某样（见 `docs/基建/框架分层与权限约定.md` 最后一节）。

**该手写的是这些**：

| 场景 | 举例 |
|---|---|
| 生成器覆盖不到的业务动作 | 审批、批量导入、状态流转 |
| 复杂查询 | 多表 join、聚合统计、跨模块检索 |
| 跨切面能力 | 文件存储这类"与业务无关、又可能换实现"的 |
| 定时任务 | Quartz job |

**只是加个字段？** 那不是手写场景 —— 改表后**重新走一遍生成器**。

## 一、改一处要顺着链全改

```
Controller（@PreAuthorize 在这层）
   ↓
Service 接口
   ↓
ServiceImpl（业务逻辑）
   ↓
Mapper 接口（Java）
   ↓
resources/mapper/**/*Mapper.xml（SQL 在这）
```

**加一个字段 = 五个文件都要动**（domain 实体还要算一个，共六个）。
少改一个的症状通常是：查询能出但存不进去，或者反过来。

**改之前先看同模块已有代码怎么写的** —— 那是最准的范例，比任何文档都准。

## 二、加一个新接口

1. **Controller 加方法** —— 照同文件里已有方法的形状写
2. **加 `@PreAuthorize`**（⚠️ 见下一节，这是最容易错的一步）
3. **Service 接口 + Impl** —— 逻辑写 Impl
4. **Mapper 接口 + XML** —— SQL 写在 XML 里，别用注解（本项目统一 XML）
5. **返回用 `AjaxResult` / `TableDataInfo`** —— **别返回裸对象**

> **接口返回的字段形状有约定**（多值 → JSON 数组、布尔 → `true`/`false`），
> `@MultiValue` / `@FlagValue` 两个注解在 Jackson 边界上做转换，**手写实体也能直接用**。
> 契约见 `docs/生成器/模板增强清单.md`。

## 三、⚠️ 权限串：两处必须逐字对上

```java
@PreAuthorize("@ss.hasPermi('biz:demoProduct:list')")
```

这个串必须和 **`sys_menu.perms` 逐字一致**。对不上的症状是**前端按钮不显示，或点了 403** ——
两种症状对应两种病，别混：

- **按钮不显示** → `sys_menu` 里没这条 `F` 记录（或 `perms` 拼错）
- **按钮点了 403** → 两处都有但**串不一致**

**新增权限要三处齐**：Controller 的 `@PreAuthorize`、`sys_menu` 的 `F` 记录、
前端的 `v-hasPermi="['biz:xxx:add']"`。

> ⚠️ **改完权限必须重新登录** —— 菜单和权限是登录时缓存进 Redis 的。
> 不重登，改了也看不到。

## 四、跨切面能力放哪

「跟具体业务无关、又可能换实现」的能力（如文件存哪）走这个模式：

- **接口 + 默认实现** → 放 `common` 模块（无条件加载）
- **可选实现** → 独立模块 + `@ConditionalOnProperty` 装配

> ⚠️ **条件注解要严格互补** —— 同一路径被两个提供者同时注册时，
> `@RequestMapping` 会**静默**赢过 resource handler：不报错，只是行为悄悄变了。
> 现成例子见 `docs/基建/文件存储.md`。

## 五、改完必须做的三件事

```bash
# 1. 重新打包 —— 直接重启 jar 不生效
mvn -f backend/pom.xml clean install -DskipTests

# 2. 重启后端 jar

# 3. 重新登录前端（权限缓存）
```

**第 1 步不能省** —— 这是本项目最高频的坑（`CLAUDE.md` 铁律第一条）。

## 排查

- **改了没生效** → **没 `mvn install`**。直接重启 jar 不会加载新代码
- **改了生成器模板 `vm/` 也没生效** → 同上，模板打在 jar 里
- **按钮不显示** → `sys_menu` 缺 `F` 记录；**按钮 403** → `@PreAuthorize` 与 `perms` 串不一致
- **权限改完看不到** → **重新登录**
- **接口返回的形状和库里对不上** → 看 `docs/生成器/模板增强清单.md` 的字段形状约定
- **加了字段但存不进去** → 五处链上漏了某处（XML 的 insert/update 最容易漏）

## 汇报

```
改动：<加了什么接口 / 改了什么逻辑>
链上文件：Controller / Service / Impl / Mapper / XML —— 各改了哪个
权限串：<新增的 perms；三处是否都齐>
打包：mvn install ✅ / 未做 ❌
验证：<接口调通了没、怎么调的 —— 调了就给请求与响应形状>
遗留：<没验的、拿不准的>
```

**没调过接口就不要说"通了"。** 打包成功 ≠ 功能正确。
